# Fixit

Fixed price. Fixed right. A booking platform for home repairs in Beirut.

Web Programming (020WBPES3) capstone project - Raymond Rechdan (240647), Ralph Assi (242320).

- `client/` React front end (Vite, React Router)
- `server/` Express REST API (PostgreSQL with Prisma)
- `docs/` wireframes and database schema
